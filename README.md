# Web Technology Laboratory (WTL) - Assignments

This repository contains the laboratory assignments completed for the **Web Technology Laboratory (WTL)** course (Semester 5).

## 📁 Repository Overview

| Folder | Topic / Project | Tech Stack |
|---|---|---|
| [**Assignment 1**](./Assignment%201) | Static Multi-Page Website | HTML5, CSS3 |
| [**Assignment 2**](./Assignment%202) | Interactive Calculator | HTML5, CSS3, JavaScript |
| [**Assignment 3**](./Assignment%203) | Dynamic Registration & Form Processing | HTML5, CSS3, JavaScript, PHP |
| [**Assignment 4**](./Assignment%204) | Full-Stack MERN Application (Portfolio & REST API) | React (Vite), Node.js, Express, MongoDB, Tailwind CSS |
| [**Assignment 10**](./Assignment%2010) | Student Management CRUD API & Serverless Functions | Node.js, Express, MongoDB / Mongoose, Vercel & Netlify Serverless Functions |

## 🛠️ Tech Stack Across Assignments
- **Frontend**: HTML5, CSS3, Vanilla JavaScript, React.js, Vite, Tailwind CSS, Framer Motion
- **Backend**: Node.js, Express.js, PHP
- **Database**: MongoDB, Mongoose
- **Cloud / Serverless**: Vercel Serverless Functions, Netlify Functions
